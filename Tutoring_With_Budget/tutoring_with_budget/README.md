# utrgv-3340-fall2026-group-project-1-group-3

## Peer Tutoring Marketplace

CSCI 3340 Software Engineering Group 3

Django application where students can post tutoring requests and tutors can apply to help them.

## Current Status

Django is initialized, tutoring app is made, and migrations have been applied.

## Local Setup

Need python and git installed

## 1. Create VENV and activate depending on OS

python3 -m venv. venv

## 2. Install dependencies

python -m pip install -r requirements.txt

## 3. Initialize local db

python manage.py migrate

## 4. Start dev server

python manage.py runserver
